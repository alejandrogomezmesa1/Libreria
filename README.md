# Libreria

Sistema de gestión de biblioteca para el control de libros, autores, categorías, usuarios y préstamos.

## Características
- Gestión de Libros (Título, Autor, Categorías asociadas).
- Gestión de Autores.
- Gestión de Categorías.
- Gestión de Usuarios y Tarjetas de Biblioteca.
- Registro y control de Préstamos y Devoluciones.

## Requisitos
- .NET 10.0 SDK o superior
- SQL Server LocalDB

## Ejecución del Proyecto
```bash
dotnet restore
dotnet build
dotnet run
```
La aplicación estará disponible en `http://localhost:5264`.
